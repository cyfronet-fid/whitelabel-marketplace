# Release 3.64.0

**Released:** 2026-09-29
**Action required after upgrade:** Optional

## What's new

### Automatic import from the Resource Catalogue

The Marketplace can now keep itself in sync with the Resource Catalogue on its own. When enabled, a scheduled job in the `worker` container runs the full import (`import:all`) every 3 minutes by default. Newly onboarded or updated catalogues, organisations, services, data sources, guidelines and vocabularies show up in the Marketplace without a manual import. The feature is **off by default**.

## Action required

### Automatic import from the Resource Catalogue

Only if you want automatic synchronisation. Manual import (`rake import:all`) keeps working as before.

1. Make sure the Resource Catalogue connection is configured in `marketplace.env` (you already have this if manual import works):

   ```env
   MP_IMPORT_EOSC_REGISTRY_URL=<resource-catalogue-api-url>
   IMPORT_CLIENT_ID=<client-id>
   IMPORT_CLIENT_SECRET=<client-secret>
   ```

2. Enable the scheduled import in `marketplace.env`:

   ```env
   AUTO_IMPORT_ALL_ENABLED=true
   # Optional - how often the import runs (default: every 3 minutes)
   AUTO_IMPORT_ALL_CRON="*/3 * * * *"
   ```

3. Restart the `worker` service:

   ```bash
   docker compose up -d worker
   ```

4. Verify: open the Sidekiq Web UI at `/admin/sidekiq` and go to the **Cron** tab. The import job should be listed and enabled. After a few minutes, recently onboarded resources should appear in the Marketplace.

More details: [Auto Import](../marketplace-deployment.md#auto-import)
