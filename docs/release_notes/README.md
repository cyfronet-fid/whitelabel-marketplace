# Release Notes for Nodes

Short, practical notes for node operators. Each release with node-relevant changes has one file here. It lists what's new and what you need to do after upgrading.

Read the notes for every version between your current one and the target version, oldest first.

For the full list of changes, see [CHANGELOG.md](../../CHANGELOG.md).

## Releases

| Version             | Action required | Summary                                      |
| ------------------- | --------------- | -------------------------------------------- |

## Adding a new release note

Copy [template.md](template.md) to `<version>.md`, fill it in following the instructions at the top of the template, and add a row to the table above (newest first).
